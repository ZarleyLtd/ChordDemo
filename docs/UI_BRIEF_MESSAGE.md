# Brief message

ChordDemo uses the shared CursorSites brief-message pattern for short feedback on the control you just used. At the moment that is the new lyric timing offset (for example "+0.25s") when you tap − or + beside the lyrics.

- Canonical spec: [cursor-sites-shared/ui/BRIEF_MESSAGE.md](../../cursor-sites-shared/ui/BRIEF_MESSAGE.md)
- Files in this repo: `assets/js/utils/brief-message.js` and `assets/css/brief-message.css`
- Sync from the shared folder with `cursor-sites-shared/scripts/sync-ui.ps1`. ChordDemo is one of the projects that script updates.
